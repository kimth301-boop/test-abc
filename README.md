# 🎰 로또 6/45 황금 행운 번호 추첨기

대한민국 동행복권 로또 6/45 규칙을 준수하는 고품질 웹 애플리케이션입니다.

## ✨ 주요 기능
- **실시간 볼 추첨기**: Canvas 2D 물리 엔진 기반 에어볼 회전 및 순차 추출 애니메이션 & 효과음
- **5게임 복권 슬립**: 실제 복권 용지 스타일의 A~E 게임 일괄 생성, 인쇄 및 복사 기능
- **맞춤 필터 추출기**: 1~45 고정수(최대 5개) 및 제외수, 홀짝 비율, 총합 구간 필터링
- **꿈 해몽 & 사주 운세**: 전통 12대 길몽 및 생년월일 기반 오늘의 재물운 번호
- **역대 통계 분석**: 최다 출현 핫넘버 TOP 10, 최소 출현 콜드넘버 TOP 10, 색상 및 홀짝 통계
- **모의 당첨 시뮬레이터**: 최신 회차 번호 대조 및 최대 50,000회 가상 추첨 몬테카를로 확률 시뮬레이션
- **번호 보관함**: 브라우저 로컬 저장소를 통한 번호 저장, 복사, 관리

## 🚀 실행 방법
```bash
# 패키지 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build
```

## 🛠️ 기술 스택
- React 19 + TypeScript
- Vite + Tailwind CSS
- Web Audio API (사운드 합성)
- HTML5 Canvas (물리 애니메이션)
- canvas-confetti, lucide-react
